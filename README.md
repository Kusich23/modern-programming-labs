## Опис предметної області

Проєкт реалізує інформаційну систему для інтернет-магазину, яка забезпечує керування каталогом товарів, клієнтами та замовленнями. Система дозволяє формувати замовлення, відстежувати їхні статуси від створення до доставки або скасування, а також обробляти оплату різними способами. Архітектура рішення побудована з відокремленням бізнес-логіки у доменну бібліотеку `OnlineStore.Domain` від клієнтського шару `OnlineStore.App`. У межах курсу проєкт послідовно розширюється від базової консольної програми до вебсервісу з постійним збереженням даних, тестами та автоматизацією збірки.
